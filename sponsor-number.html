암웨이 후원자 번호란?

한국암웨이에 회원가입하려면 후원자 번호를 반드시 입력해야 해요. 번호가 없으면 가입을 끝낼 수 없어요.

후원자 번호는 왜 필요한가요?

암웨이는 새로 가입하는 회원을 기존 ABO가 안내하고 돕는 방식이에요. 그래서 가입할 때 나를 안내해 줄 ABO(후원자)의 번호를 입력하게 되어 있어요. 가입 후 제품 사용법이나 주문 방법이 궁금할 때 후원자에게 물어볼 수 있어요.

어디에 입력하나요?

ABO 가입

로그인/회원가입 → 회원가입 → ABO 회원가입 하기 → ‘후원자 ABO 번호’ 칸에 입력 후 확인

Member 가입

로그인/회원가입 → 회원가입 → Member로 회원가입 하기 → 후원자 ABO 번호 입력 후 후원자확인

카카오로 가입

카카오 동의를 마치고 암웨이 사이트로 돌아오면 나오는 후원자 입력 칸에 입력
✅ 번호를 입력하고 확인을 누르면 후원자 이름이 나와요. 김**으로 나오면 제대로 입력된 거예요.
